# AlbumShot（图文融合）

为 Daydream **音乐相册**提供章头图文版式。写文章 → **组件插入** → **图文融合**。

## 后台用法（1.3）

1. 右侧 **附件图片库** 以缩略图列出本文及近期图片附件（上传后可点「刷新附件库」）。
2. **点击**选用，或 **拖到左侧预览区** 投放。
3. 单图：投放后即替换主图并按版式预览；多图/画布：逐张加入画布，可再拖动排版。
4. 确认后点底部「插入」。

> 根因说明：Typecho 附件列表里 `a.insert` 的 `href` 常为 `###`，真实地址在 `li[data-url]`。旧版下拉框误用文件名，导致无法预览。

## 分类

| 分类 | 说明 |
|------|------|
| 单图 | 与章节标题的关系：横幅 / 叠字 / 分栏 / 环绕。图片按原比例，不裁切拉伸 |
| 双图 | 左右对开、主副、叠压 |
| 多图 | 一大两小、三联、四宫 |
| 自由画布 | 多图拖拽定位、缩放；坐标为画幅百分比，窄屏整页等比缩放 |

## 短代码

单图：

```
[album-shot layout="overlay" src="/usr/uploads/a.jpg" alt="现场"]
```

多图 / 画布：

```
<div>
[album-board ratio="3:2"][img src="https://..." x="2" y="6" w="47"][img src="https://..." x="51" y="6" w="47"][/album-board]
</div>
```

`x` `y` `w` 为相对画幅的百分比。图片高度随自身宽高比，不拉伸。

**Markdown 注意**：相邻 `[...][...]` 会被解析成引用链接。组件插入会自动包一层 `<div>`；手写时也请包在 HTML 块内。从 1.1 升到 1.2 后请在后台对 AlbumShot **禁用再启用**，以注册 Markdown 保护钩子。
