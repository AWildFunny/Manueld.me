# AuthorNotice

作者申明色块插件。短代码 `[notice]…[/notice]`；在 **Daydream** 写文章侧栏「组件插入」中可用（主题内置面板壳，无需额外插件）。

## 启用

1. 后台启用 **AuthorNotice**
2. 使用 Daydream 主题时，写文章/页面右侧会出现「组件插入」

## 短代码

```
[notice title="标题" color="#4E7289" text="#ffffff" radius="12" shadow="1"]
正文，支持空行分段与 [链接文字](/path)
[/notice]
```

插件设置可改默认背景色 / 文字色。
